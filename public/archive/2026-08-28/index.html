海尔、美的、格力集体加码具身智能：家电企业开始抢家庭机器人入口

来源：新浪科技 / 快科技 时间：2026-08-28 评分：94

家电巨头的机器人路线正在分化：海尔主打家庭服务，美的走工业与家庭双线，格力强调自研制造能力。

新浪科技转载快科技消息称，今年海尔、美的、格力都把布局重点延伸到具身智能。海尔发布“海娃”家务、清洁、陪伴三类家庭服务机器人；美的既有面向工业的“美罗 U”，也在测试家庭“美拉”系列；格力则强调整机和零部件自研自产。

报道还提到，海信、TCL、科沃斯、方太等家电企业也在今年展示具身智能产品，形态覆盖家务、清洁、陪伴、烹饪等方向。家电企业的优势在渠道、场景和供应链，但真正进入家庭还要跨过成本、稳定性和用户信任门槛。

小编有话说这条不是单纯“机器人热”，而是竞品边界在变。未来厨房的对手可能不只是一台烟机或蒸烤箱，而是能接管家务、清洁和陪伴任务的家庭智能体。

国家政策 · AI技术趋势

央视新闻聚焦“未来五年”：智能机器人、具身智能与人工智能+场景被点名

来源：央视新闻 时间：2026-08-28 05:47 评分：90

工信部相关负责人介绍“十五五”新型工业化方向，智能机器人、具身智能、人工智能+、机器人+等被放进产业化落地框架。

央视新闻今天刊文梳理未来五年新兴产业、新场景和新材料发展方向。文章提到，将加快打造集成电路、航空航天、生物医药、低空经济、新型储能、智能机器人等新兴支柱产业。

在应用场景上，政策信号更直接：人工智能+、机器人+、工业互联网+等重大场景会继续被培育，创新成果要在真实场景中测试、验证、迭代，并推动轻量化、低成本、易部署的行业解决方案。

小编有话说这对未来厨房很关键。政策不是只在远处喊口号，而是在提醒企业：AI 要进入研发设计、生产制造、质检运维和消费场景，最终比拼的是能不能形成可复制、可部署的行业方案。

AI技术趋势 · 用户趋势

36氪观察 Agent 硬件出海：AI 从屏幕里走出来，先寄居在眼镜、戒指和录音器上

来源：36氪 / 亿邦动力 时间：2026-08-28 09:27 评分：88

AI Agent 正从软件产品外溢到可穿戴和办公硬件，硬件创业进入“AI 原生”与全球化验证阶段。

36氪经授权发布亿邦动力文章指出，Agent 落地正在从软件进入硬件。眼镜、耳机、戒指、录音器等熟悉形态开始承载健康、工作和陪伴类 Agent 功能，部分中国品牌已经在海外验证市场。

文章也给出一个冷静判断：硬件不是“把 AI 塞进去”就会被用户接受。AI Pin、Rabbit R1 的失败提醒行业，产品要尊重已有习惯，聚焦高频真实需求，并在订阅服务、售后、合规和用户信任上持续兑现。

小编有话说厨房里的 AI 也要学会做减法。最好的入口未必是大屏，而可能是一个自然存在的设备形态：烟机、灶具、冰箱、眼镜或耳机，关键是能不能真正减少用户负担。
